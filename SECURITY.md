# Security and research conduct

This project reads public workflow configuration. It must not execute scanned project code or test attacks against third-party repositories.

Keep raw snapshots, identities, suspected credential material and unreviewed findings private. Use a private channel to contact an affected maintainer. Do not open a public issue containing a working attack, secret value, or identifying exposure list.

Use dedicated owned repositories and synthetic canaries for live evaluation. No production credentials, Zynga systems, or private employer source are required.

The scanner is heuristic. A flag is a configuration observation, not a vulnerability confirmation, security certification, or assurance of absence.
